# Yagi-Uda-Antenna-433MHz
Design and simulation of a 5-element Yagi-Uda antenna for 433 MHz using ANSYS HFSS.


This project presents the design, simulation, fabrication, and analysis of a 5-element Yagi-Uda antenna operating at 433 MHz.

The antenna was designed using ANSYS HFSS and optimized for ISM band applications such as LoRa, RFID, and long-range IoT communication systems.

## Project Overview

The antenna consists of:
- 1 Reflector
- 1 Driven Element
- 3 Directors

The design was implemented using copper wire elements with a radius of 0.95 mm and optimized using full-wave electromagnetic simulation techniques.

## Software Used

- ANSYS HFSS 2023 R1

## Features

- 433 MHz ISM band operation
- Directional radiation pattern
- High directivity
- HFSS full-wave simulation
- Fabricated prototype
- Return loss and radiation analysis

## Technical Specifications

- Operating Frequency: 433 MHz
- Antenna Type: 5-Element Yagi-Uda
- Wire Radius: 0.95 mm
- Element Spacing: 0.2λ
- Simulated Return Loss (S11): -18.9 dB
- Bandwidth: ~48 MHz

## Design Parameters

- Reflector Length: 388 mm
- Driven Element Length: 346.41 mm
- Director Lengths: Optimized for 433 MHz resonance

## Results

The antenna demonstrated:
- Proper resonance near 433 MHz
- Directional end-fire radiation pattern
- Stable impedance characteristics
- Improved gain and directivity

The simulated radiation pattern and S11 plots verified correct antenna operation.
